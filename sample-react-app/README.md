# Sample React Application

This is a sample React application built with TypeScript. It serves as a template for creating a new React project.

## Project Structure

```
sample-react-app
├── public
│   └── index.html          # Main HTML file
├── src
│   ├── index.tsx          # Entry point for the React application
│   ├── App.tsx            # Main App component
│   ├── index.css          # Global CSS styles
│   ├── App.css            # Styles specific to the App component
│   ├── components          # Contains reusable components
│   │   └── ExampleComponent.tsx
│   ├── pages               # Contains page components
│   │   └── Home.tsx
│   ├── hooks               # Contains custom hooks
│   │   └── useExample.ts
│   ├── utils               # Contains utility functions
│   │   └── api.ts
│   ├── types               # Contains TypeScript types and interfaces
│   │   └── index.d.ts
│   ├── serviceWorker.ts    # Service worker for offline support
│   └── setupTests.ts       # Testing environment setup
├── package.json            # npm configuration file
├── tsconfig.json           # TypeScript configuration file
├── .eslintrc.json          # ESLint configuration file
├── .gitignore              # Git ignore file
└── README.md               # Project documentation
```

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd sample-react-app
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Run the application:**
   ```
   npm start
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` to view the application.

## Features

- TypeScript support for type safety
- Custom hooks for reusable logic
- Organized folder structure for components, pages, and utilities
- Service worker for offline capabilities
